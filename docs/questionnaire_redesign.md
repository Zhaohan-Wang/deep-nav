# 关末量表重构说明（event-attribution-2.2）

## D001 暴露的问题

D001 的五关都完成了双方量表。旧量表第一题是“刚才任务结果最主要由什么造成”，它把至少三种对象混在了一起：整局成功或失败、碰撞或解体、实验操纵的具体航向异常。因此同一个 `primary_cause` 编码不能回答“被试认为航向为什么偏了”。

旧答案也显示了这种歧义：前四关均成功，最后一关失败；领航员在正式任务 02–04 连续选择“系统”，驾驶员在任务 02 选择“搭档”、任务 03 选择“系统”、任务 04 选择“外部环境”。这些答案可能是在解释局级结果，也可能是在解释某次异常，无法从数据中区分。D001 应作为试测数据保留，不能把旧字段直接重命名后与新版合并。

按新版操作定义对 D001 的轨迹做事后回放，训练关至任务 04 约有 1、0、2、3、6 次严重航向偏离。最后一关同时有 31 次碰撞、3 次解体并超时，说明如果不先指定事件对象，被试很容易只评价“这局为什么失败”。新版从下一组数据开始由运行时直接计数，并在 `mission_end` 与量表答案中同时保存；事后回放数字只用于验证阈值，不回写 D001 原始文件。

## 结构决策

### 1. 先呈现事件事实，再询问原因

第一页用四张独立指标卡显示严重航向偏离、航点方向改变、飞船横向位移、碰撞和解体次数；严重偏离使用琥珀色，航点与横移事件使用青色，数值放大显示。归因题明确问“上述航向事件”，不再问宽泛的任务结果。事件提示只陈述可观测变化，不补充实验条件中的原因，避免把模糊条件意外变成明确条件。操作定义不展示给被试，避免增加无关阅读负担；玩家只看到结果计数，完整阈值保留在研究说明和事件日志中。

严重航向偏离定义为：速度不低于 3、离当前航点至少 8 个世界单位时，船头与航点方向相差至少 60° 并持续至少 2 秒。恢复到 40° 以内后才允许开始下一次计数。阈值、持续时间和事件位置均写入事件日志，后续可以做敏感性分析。

### 2. 区分驾驶员与领航员

需要区分题干，但不改变编码含义：

| 编码 | 领航员看到的原因 | 驾驶员看到的原因 |
|---|---|---|
| 1 | 我的航点引导：落点、时机、路线 | 我的操控：转向、速度、响应 |
| 2 | 驾驶员操控：转向、速度、响应 | 领航员引导：落点、时机、路线 |
| 3 | 导航信息：航点、方向、仪表 | 同左 |
| 4 | 飞船响应：转向、变速不如预期 | 同左 |
| 5 | 航行环境：外力、障碍、航道 | 同左 |
| 6 | 多种原因：没有单一主因 | 同左 |
| 7 | 无法判断：信息不足 | 同左 |

原来的“飞船或导航系统”混合了信息呈现与物理响应，玩家很难知道它具体指什么。新版将其拆成编码 3“导航信息或显示”和编码 4“飞船的操控响应”，并把外部环境单列为编码 5。搭档信任题也分别指向“驾驶员能否准确执行航点”和“领航员能否提供及时且可执行的航点”。这样既保留岗位内容效度，也能用统一编码比较两种角色。

“多种原因共同作用”和“信息不足”分开保留：前者表示被试确实观察到多个来源，后者表示证据不足。强迫两类被试在人物、设备或环境中任选一个，会制造不可解释的伪精确答案。

### 3. 不按成功/失败改动核心量尺

成功与失败会影响归因，这是应该保留并建模的结果变量，而不是用两套不同题目把它混入测量工具。新版只区分上下文提示：成功时说明“不评价整局成功”，失败时说明“不把失败本身当作原因”；核心事件归因与 1–7 量尺保持完全一致。分析时把 `outcome_success` 作为关级协变量或分层因素。

### 4. 分开信任与依赖意愿

旧版只有一项搭档信任、一项系统信任和一项继续依赖搭档，无法区分信任判断与行为意愿。新版对搭档和系统分别记录：

- 能力/可靠性；
- 可预期性；
- 下一段任务的依赖意愿。

这是适合每关重复施测的短状态量表，不宣称等同于任何未经删改的完整既有量表。论文中应报告原文、译文、计分、施测时点和本样本的内部一致性；若正式研究的主要因变量就是“信任”，应在试测后决定是否改用完整且经验证的中文量表。

## 文献依据

- McAuley、Duncan 与 Russell 的 CDS-II 将原因属性区分为因果位置、稳定性、个人控制和外部控制，说明单一“主要原因”分类不足以代表完整归因构念。本实验当前只需要事件来源归因，因此不冒充 CDS-II；若论文假设涉及可控性或稳定性，应完整加入对应维度。[CDS-II 量表与原始出处](https://epl.illinois.edu/cds-2)
- Jian、Bisantz 与 Drury 通过经验研究提出 12 项人—自动化信任量表，说明一个单题“系统信任”不能被表述为完整的验证量表。[论文 DOI](https://doi.org/10.1207/S15327566IJCE0401_04)
- Lee 与 See 区分信任和适当依赖，并强调情境与系统表现会动态影响信任。新版因此把可靠性/可预期性判断与后续依赖意愿分别记录。[Human Factors 论文](https://pubmed.ncbi.nlm.nih.gov/15151155/)
- 成功/失败本身会系统性影响归因，而且题目措辞会改变这种效应。因此核心题目跨结果保持一致，只把结果作为上下文和分析因素。[归因措辞元分析 DOI](https://doi.org/10.1207/s15324834basp0701_3)

## 新旧字段

旧字段 `primary_cause`、`attribution_confidence`、`partner_trust`、`system_trust`、`continued_reliance` 从新版起停止生成。新版量表答案包含：

- `instrument_version = event-attribution-2.2`；
- `event_primary_cause`、`event_attribution_confidence`；
- `partner_capability_trust`、`partner_predictability`、`partner_reliance_intent`；
- `navigation_information_trust`、`ship_response_predictability`、`system_reliance_intent`；
- 任务结果与被试作答时看到的三个客观事件计数。

分析脚本必须按 `instrument_version` 分层，不能把旧版和新版同名合并成一列。
