# UI interaction audio sources

The named runtime OGG files are short, silence-trimmed and level-matched
selections from the user-provided Pixabay downloads:

- `ui_hover.ogg` — `juniorsoundays-ui-sound-56-527824.mp3`
- `ui_press.ogg` — `juniorsoundays-ui-sound-57-527851.mp3`
- `ui_choice.ogg` — `juniorsoundays-ui-sound-24-527861.mp3`
- `ui_slider_tick.ogg` — `juniorsoundays-ui-sound-95-532185.mp3`
- `ui_page_turn.ogg` — `juniorsoundays-ui-sound-72-527849.mp3`
- `ui_confirm.ogg` — `juniorsoundays-ui-sound-02-527862.mp3`
- `ui_popup_open.ogg` — `litupsubway-ui-open-sfx-513358.mp3`
- `ui_popup_close.ogg` — `litupsubway-ui-close-sfx-513359.mp3`

The source files contained 0.35–0.92 seconds of trailing silence. Runtime
versions keep only the useful transient and decay so hover, click and slider
feedback starts immediately.
